How this works

The agent reads only, and only this client's data. Finding text comes from monitored systems and the open internet, so it is treated as untrusted. SABINE checks the recommendation against the verdict and the findings the agent actually read, builds the target itself, and the autonomy policy decides what happens next. Each tool call is on the ledger with the SHA-256 of the result shown here.
